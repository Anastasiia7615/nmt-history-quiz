# НМТ Історія України — Картки

Інтерактивні картки для підготовки до НМТ з історії України.

## Що є

- **Режим «Теми»** — картки по темах 11–30
- **Режим «Джерела»** — уривки з історичних джерел (як на НМТ)
- **Режим «Усі»** — все разом
- Фільтр по окремих темах
- Кнопки Вперед / Назад
- Натисни на картку — побачиш відповідь
- Підтримка зображень (можна додавати)

## Як запустити локально

Просто відкрий `index.html` у браузері.

## Як викласти на GitHub Pages

1. Створи новий репозиторій на GitHub
2. Завантаж усі файли з цієї папки
3. Settings → Pages → Source: Deploy from a branch → main → / (root)
4. Через 1–2 хвилини сайт буде доступний за адресою `https://твій-нік.github.io/назва-репо/`

## Структура

```
nmt-history-quiz/
├── index.html
├── style.css
├── app.js
├── data.js          ← всі питання і відповіді
├── images/          ← сюди можна класти картинки
└── README.md
```

## Як додати нові картки

Відкрий `data.js` і додай об’єкт у масив `cards`:

```js
{
  topic: "21",
  topicName: "Тема 21",
  question: "Твоє питання?",
  answer: "Правильна відповідь",
  image: "images/photo.jpg"   // необов’язково
}
```

Для режиму «Джерела» використовуй `topic: "sources"`.
